# Desafio de Projeto: Dashboard de Vendas (Xbox) no Excel

Repositório criado para a entrega do desafio final de projeto da **DIO (Digital Innovation One)**, focado na transformação de dados brutos em um dashboard visual, interativo e analítico no Excel.

## 🎯 Objetivo do Projeto
O objetivo principal foi estruturar um painel de controle (Dashboard) de vendas dinâmico, permitindo a visualização clara de Indicadores Chave de Desempenho (KPIs), o comportamento das vendas de produtos Xbox e o apoio à tomada de decisões estratégicas baseadas em dados.

---

## 🛠️ Arquitetura e Estrutura da Planilha

A ferramenta foi construída seguindo uma separação limpa de camadas de dados e apresentação:
1. **Assets**: Recursos visuais, ícones e elementos de identidade visual utilizados na construção do layout.
2. **Bases**: Repositório dos dados brutos de transações e vendas tratados para o projeto.
3. **Cálculos**: Aba intermediária dedicada a fórmulas, tabelas dinâmicas e consolidação de métricas que alimentam o painel visual.
4. **Dashboard**: Painel principal interativo, contendo gráficos, cartões de KPIs e filtros visuais (Segmentações de Dados / Slicers).

---

## 🚀 Principais Tecnologias e Recursos Aplicados
- **Microsoft Excel Avançado**: Uso de fórmulas de agregação, tabelas e gráficos dinâmicos.
- **Data Visualization**: Aplicação de boas práticas de design de painéis gerenciais (UI/UX em planilhas).
- **Segmentação de Dados (Slicers)**: Interatividade para filtrar períodos, regiões ou categorias de produtos em tempo real.
- **GitHub**: Versionamento de código e documentação técnica profissional.

## 🚀 Como Utilizar

1. Faça o download do arquivo `.xlsx` disponível na pasta `data/`.
2. Abra o arquivo no **Microsoft Excel** (versão 2016 ou superior recomendada para suporte total a recursos visuais e segmentações).
3. Utilize os filtros interativos para explorar os cenários de vendas.
